# نور الهدى — مشروع أندرويد تأسيسي

هذا مشروع Flutter أولي لتطبيق **نور الهدى**. يحتوي حالياً على:
- شاشة ترحيب تظهر مرة واحدة.
- واجهة عربية باتجاه RTL.
- ألوان أخضر زمردي وذهبي.
- أقسام أولية للموسوعة، وقائمة جانبية وإعدادات أولية.

**تنبيه مهم:** هذه ليست الموسوعة المكتملة بعد. لا توجد فيها حالياً آلاف الكتب، ولا بحث حقيقي، ولا قارئ كتب كامل، ولا ترجمة فعلية للواجهات، ولا تنزيل لمحتوى الكتب. هذه مراحل تطوير لاحقة.

## كيف تحصل على APK باستخدام الهاتف فقط؟

أعددنا ملف بناء آلياً في:
`.github/workflows/android.yml`

يمكن لـ GitHub أن يبني التطبيق في السحابة دون تثبيت أدوات برمجة على هاتفك.

1. افتح GitHub من المتصفح وسجّل حساباً أو أنشئ حساباً.
2. أنشئ مستودعاً جديداً باسم `noor-alhuda`، واجعله خاصاً إن رغبت.
3. ارفع **محتويات هذا المجلد بعد فك ضغطه** إلى المستودع، مع الحفاظ على مجلد `.github` ومحتوياته. لا ترفع ملف ZIP نفسه فقط.
4. افتح تبويب `Actions` في المستودع، ثم اختر سير العمل `Build Noor Al-Huda Android APK` واضغط `Run workflow` إذا لم يبدأ تلقائياً.
5. انتظر انتهاء البناء بنجاح.
6. افتح نتيجة التشغيل، وانزل إلى قسم `Artifacts`، ثم نزّل `noor-alhuda-android-apk`.
7. فك ضغط الملف الذي نزّلته؛ ستجد `app-release.apk`. افتحه على هاتف أندرويد وثبّته. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

قد تختلف أسماء الأزرار قليلاً حسب لغة GitHub وتحديث واجهته. لا تشارك كلمة مرورك أو رموز التحقق مع أي شخص.

## متطلبات مهمة قبل إصدار عام

- إضافة هوية Android النهائية واسم الحزمة.
- اختبار التثبيت والتشغيل على أجهزة مختلفة.
- بناء قاعدة محتوى موثوقة وبيانات وصفية للكتب.
- التحقق من حقوق نشر الكتب قبل تضمينها أو توزيعها.
- تنفيذ قارئ الكتب والبحث والتنزيل دون إنترنت وتعدد اللغات.
- مراجعة علمية للمحتوى ونسبة الكتب إلى مؤلفيها.

## التشغيل محلياً (اختياري، يحتاج كمبيوتر)

```bash
flutter pub get
flutter run
flutter build apk --release
```
