# نور الهدى — الموسوعة الإسلامية

تطبيق Flutter عربي باتجاه RTL، يهدف إلى تنظيم فهارس الكتب الإسلامية والدروس التعليمية.

## الحالة الحالية
هذه نسخة تأسيسية قيد التطوير وليست إصداراً جاهزاً للنشر بعد.

الموجود حالياً:
- واجهة عربية RTL بهوية خضراء وذهبية.
- شاشة افتتاحية وترحيب تظهر في أول تشغيل.
- فهرس أولي للكتب مع التصنيف والبحث حسب العنوان والمؤلف والقسم.
- صفحة بيانات الكتاب والمفضلة المحلية.
- قسم للمسلمين الجدد وقسم تعليمي للأطفال.
- سير عمل GitHub Actions لبناء APK وإرفاقه كملف artifact.

ما يزال مطلوباً قبل النشر:
- توفير النصوص الكاملة للكتب من مصادر رقمية موثوقة ومسموح بإعادة توزيعها، مع بيانات الطبعة والمحقق والمصدر.
- إضافة قارئ كتب وفهرس داخلي وعلامات مرجعية وبحث داخل النص.
- تصميم تنزيلات اختيارية وحزم قراءة تعمل دون اتصال، مع بيان أحجامها.
- مراجعة علمية وتحرير لغوي وحقوق نشر لكل مادة.
- اختبارات على أجهزة Android فعلية، ثم تجهيز الأيقونة ولقطات الشاشة وسياسة الخصوصية وبيانات المتجر.

## التطوير والبناء
يتطلب المشروع Flutter stable وDart 3.3 أو أحدث.

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

يمكن تنزيل APK من GitHub Actions بعد نجاح سير العمل، من قسم Artifacts في تشغيل البناء.

## سياسة المحتوى
لا تُدرج نصوص كتب أو أحاديث أو أحكام من الذاكرة على أنها نصوص محققة. يجب توثيق مصدر كل نص، والتحقق من دقة النقل، ومراعاة حقوق النشر وشروط إعادة التوزيع. وجود عنوان الكتاب في الفهرس لا يعني أن نصه الكامل متاح داخل التطبيق.


## مصادر النصوص المرفقة وحالة المراجعة

- **القرآن الكريم:** نص الرسم العثماني من مشروع تنزيل (Tanzil), الإصدار 1.1. يجب إبقاء النص كما هو دون تغيير، وإظهار إشعار حقوق المشروع ورابطه داخل التطبيق. شروط المشروع تسمح بإعادة التوزيع الحرفي مع النسبة، ولا تسمح بتغيير النص.
- **صحيح البخاري وصحيح مسلم وسنن أبي داود وجامع الترمذي وسنن النسائي وسنن ابن ماجه:** النصوص العربية الرقمية الحالية من مشروع `fawazahmed0/hadith-api`، مثبتة على الفرع `1`. هذه ملفات بيانات مفتوحة المصدر، لكنها لا تغني عن مقابلة النصوص على طبعات محققة معتمدة قبل اعتمادها علمياً أو الاستدلال بها. لا تُعرض أحكام تصحيح أو تضعيف إلا مع مصدر مستقل واضح.
- **مصنفات الإمام الشافعي الموجودة:** `الرسالة` و`جماع العلم` و`اختلاف الحديث` مأخوذة من سجلات OpenITI المحددة داخل بيانات كل ملف. بيانات الطبعة/النسخة مسجلة في حقل `edition`، ويجب مراجعتها قبل النشر التجاري أو إعادة التوزيع.
- لكل ملف بيانات، تُحفظ حقول المصدر والطبعة وملاحظة المراجعة بجانب النص لتظهر في قارئ الكتاب. وجود ملف رقمي لا يعني أنه خضع بعد لمقابلة علمية مستقلة.
- لا تُنشأ نصوص كتب مفقودة من الذاكرة، ولا يُستكمل أي كتاب بالتخمين. الكتب التي لا تتوفر لها نسخة موثقة ومسموح بإتاحتها تبقى في الفهرس مع توضيح أن النص غير مرفق.
